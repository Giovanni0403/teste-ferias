# teste-ferias

Criar um site onde a pagina inicial é um lugar onde a pessoa ve melhores lugares para se viajar nas ferias, os melhores avbaliados no mundo
E criar uma pagina para cada lugar mostrando oq fazer nessas cidades, oq conhecer, passeios.
No menu criar uma lupa para pessoa pesquisar qual lugar ela gostaria de saber e dar opcao de clicar para acessar a pagina daquele lugar 
Conforme na pagina inicial tiver uma breve descricao e uma imagem da cidade tera um botao de saber mais para q a pessoa ja acesse aquela pagina
E fazer uma pagina de contato para que caso a pessoa necessite fazer alguma pergunta ou alguma avaliaçao ela tenho como entrar em contato 

na pagina q diz sobre tal pais colocar fotos de passeio, da cidade , de praias ou algum ponto de historia do lugar para q nao tenha apenas textos
